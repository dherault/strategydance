# Typography

Oswald, at 400 only, sets the titles `h1` to `h3` in secondary, tracked tight: `font-display`,
also reachable as `font-heading`. Inter sets everything else: 400 for body, 500 for labels, 600
for emphasis, through `font-sans`. Sizes are Tailwind's `text-*` scale.

## Display

Set as tight as its headlines are, Oswald's descenders hang below its lines, by 0.14em at a line
height of 1.1. A box that hides what overflows it would cut them off, so the room they need is
kept below the last line, worked out from the text's own size and line height, as padding taken
back by a negative margin: the layout does not move. Under a line height of 1.05 it keeps less than
the deepest descenders need, so that a clamp never shows the top of the line it hides.

- **A display text that clips itself gets the room without asking.** An `h1` to `h3`, or anything
  in `font-display` or `font-heading`, that is a `textarea` or an `input`, or clamps or truncates
  its text, takes it from a rule in `index.css`. It takes no bottom margin of its own, since the
  room is one: set it apart with the gap above what follows
- **A box that clips display text it does not set itself** takes `descender-room`, in the size of
  the text it holds, as a card's wrapper around a top priority does
- **`RichText` keeps the room of a heading it ends on** inside itself, so any box that clips it
  keeps the descenders, unless that box keeps the room already with `descender-room`. FitText
  counts its own room as it fits
